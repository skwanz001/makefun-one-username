One word, one username, one reward: this entry writes the entrant's own make.fun username — `kripsang-sekawan` — and nothing else to `/output/entry.txt`. A judge model reads two usernames at a time and picks the one that feels funnier or more interesting.

## Run it

```sh
python3 main.py
```

The program writes exactly `kripsang-sekawan` (16 characters, no trailing newline, no extra bytes) to `/output/entry.txt`, which the sealed gate checks is UTF-8 text of 1 to 30 characters, not only white space.
